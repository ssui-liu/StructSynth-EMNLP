### 1.6 数学定界符三种并存（OpenReview 渲染风险）

实测：iRH3 用 `\( \)` ×8，q74j 用 `$…$` ×15（含 `$\pm$` ×4、`$R^2$` ×3），GR/7Wh2 用 unicode（R²）与纯文本。OpenReview 的 MathJax 只认 `$…$`，**`\( \)` 大概率原样露出为文本**——iRH3 是必修项。统一方案（推荐彻底去 MathJax，RePair 四份文件零数学依赖的做法）：

- `\(n \in \{20,50,100,200\}\)` / `$n\in\{20,50,100,200\}$` → `n ∈ {20, 50, 100, 200}` 或 `n = 20–200`
- `\(n\leq 200\)` → `n ≤ 200`；`$n=100$` → `n = 100`；`$n$` → `n`
- `$\pm$` → `±`；`$R^2$` → `R²`（与 GR/7Wh2/iRH3 现状一致）
- 改完后 grep 验证：`\(`、`$` 双双归零
