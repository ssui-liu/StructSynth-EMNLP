## P0：必须修复（影响审稿评分或格式合规）

### P0-1｜Abstract 缺少具体定量结果
- **来源：** L1 (Section Structure)
- **位置：** `sections/abstract.tex`
- **问题：** Abstract 声称 "achieves state-of-the-art downstream utility and privacy preservation" 但没有任何数字支撑。EMNLP 审稿人会认为 abstract 空泛。
- **修复：** 加入至少一个核心数字，如 "achieving an average rank of 1.00 across six datasets and outperforming the strongest baseline by 1.65 AUC points."

### P0-2｜缺少 Ethics / Broader Impact 声明
- **来源：** L10 (EMNLP Compliance)
- **位置：** 需新增段落（可附加在 `sections/limitations.tex` 末尾或单独一节）
- **问题：** 论文涉及合成数据生成，有双用途风险（伪造记录、偏差传播、敏感数据发送至商用 API），但全文无任何伦理讨论。EMNLP Responsible NLP Checklist 对此有明确要求。
- **修复：** 添加 3–5 句 Ethics 声明，覆盖：(1) 合成数据的潜在滥用风险；(2) 训练数据偏差可能被结构保持式合成放大；(3) 使用商用 LLM API 处理敏感数据集的隐私考量。

### P0-3｜缺少计算成本报告
- **来源：** L10 (EMNLP Compliance)
- **位置：** `sections/appendix.tex`（已有 token usage 表，但不够）
- **问题：** 未报告 wall-clock time、API 总费用（美元）、baseline 训练硬件。Responsible NLP Checklist 要求报告计算资源。
- **修复：** 在 appendix token usage 部分补充：每个数据集的总 API 调用次数、总费用估算、wall-clock 时间、baseline DGM 训练所用硬件。

### P0-4｜缺少代码/数据开源承诺
- **来源：** L10 (EMNLP Compliance)
- **位置：** `sections/experiments.tex` 或 `sections/limitations.tex`
- **问题：** 全文未提及代码发布计划或匿名仓库链接，严重影响可复现性评分。
- **修复：** 加一句 "Code and data will be released upon acceptance" 或提供匿名 GitHub 链接。

### P0-5｜"Structural Fidelity" 标题与 "Statistical Fidelity" 指标命名冲突
- **来源：** L4 (Word Precision)
- **位置：** `sections/experiments.tex:157`
- **问题：** 小节标题 "Structural Fidelity under Ground-Truth Graphs" 中的 "Structural Fidelity" 极易与全文使用的评估指标 "Statistical Fidelity" 混淆。该小节实际讨论的是图结构恢复质量（SHD），而非分布保真度。
- **修复：** 改标题为 `\subsection{Structure Recovery under Ground-Truth Graphs}` 或 `\subsection{Graph Recovery Quality}`。

### P0-6｜references.bib 有 153 个孤立条目（73% 未引用）
- **来源：** L6 (Citations & References)
- **位置：** `Latex-EMNLP/references.bib`
- **问题：** bib 文件包含 211 条目，仅 58 条被引用。含有量子物理、ICA 等完全无关领域的文献，明显从其他项目复制。提交时可能引起审稿人质疑。
- **修复：** 清理 bib 文件，只保留已引用的 58 条。

### P0-7｜qian2023synthcity 已发表 NeurIPS 2023，bib 仍标为 arXiv
- **来源：** L6 (Citations & References)
- **位置：** `references.bib` 中 `qian2023synthcity` 条目
- **问题：** SynthCity 已正式发表于 NeurIPS 2023，但 bib 仍为 `@misc` arXiv 格式。审稿人可能认为作者文献调研不够充分。
- **修复：** 更新为 `@inproceedings`，补充 NeurIPS 2023 信息。同时检查 `ban2023causal`、`antonucci2023zero`、`jiralerspong2024efficient` 是否也已正式发表。

## P1：强烈建议修复（明显影响可读性或专业性）

### P1-1｜12 个 appendix 公式缺少句末标点
- **来源：** L8 (Math Notation)
- **位置：** `sections/appendix.tex` 行 56–289（所有 display equations）
- **问题：** method.tex 的 5 个公式均正确加了句号，但 appendix 的 12 个公式全部缺少句末标点（句号或逗号），不符合学术排版规范。
- **修复：** 逐一为 appendix 中的 display equation 添加句号或逗号（视句法结构而定）。

### P1-2｜所有 17 个公式编号但均未被引用
- **来源：** L8 (Math Notation)
- **位置：** 全文所有 `\begin{equation}` 环境
- **问题：** 所有公式使用 `equation` 环境（自动编号），但无一添加 `\label{eq:...}`，也无任何 `\ref{eq:...}` 引用。编号而不引用是最差的状态。
- **修复：** 二选一：(a) 给每个公式加 `\label` 并在正文中用编号引用；(b) 改为 `equation*` 取消编号。

### P1-3｜method 与 algorithm 之间符号不一致（bold vs non-bold）
- **来源：** L8 (Math Notation)
- **位置：** `sections/method.tex` vs `sections/appendix.tex` Algorithm 1
- **问题：**
  - 数据矩阵：method 用 `\mathbf{X}_{train}`（加粗），algorithm 用 `X_{train}`（不加粗）
  - 合成向量：method 用 `\tilde{\mathbf{x}}_j`（加粗），algorithm 用 `\tilde{x}_j`（不加粗）
  - 属性集合：method 用 `\mathbf{A}`（加粗），algorithm 用 `A`（不加粗）
- **修复：** 统一为 method 的加粗版本，在 Algorithm 中同步更新。

### P1-4｜主文与 appendix 数据集下标字体不一致
- **来源：** L8 (Math Notation)
- **位置：** `method.tex` / `experiments.tex` 用 `\mathtt{}`，`appendix.tex` 用 `\text{}`
- **问题：** 同一符号 `\mathcal{D}_{train}` 在主文用 `\mathtt{train}` 渲染，在 appendix 用 `\text{train}` 渲染，字体不同。
- **修复：** 统一为 `\mathtt{}`（与主文保持一致）。

### P1-5｜"perform notably weaker" 语法错误
- **来源：** L5 (Grammar & Syntax)
- **位置：** `sections/experiments.tex` Section 4.2.1
- **问题：** "perform notably weaker" 中 "weaker" 是形容词，不能修饰动词 "perform"。这是明确的语法错误。
- **修复：** 改为 "are notably weaker" 或 "perform notably worse"。

### P1-6｜Introduction 缺少对 3 个实验的预告
- **来源：** L0 (Narrative Arc)
- **位置：** `sections/introduction.tex`（contribution list 末尾）
- **问题：** 读者在 Introduction 结束时不知道后文会有 SHD 结构恢复评估（Sec 4.4）、样本量敏感性实验（Sec 4.5）、不同 LLM 实验（Sec 4.6）。这三个实验缺乏前文铺垫。
- **修复：** 在 contribution list 后加一句："We further validate robustness by evaluating structure discovery against ground-truth graphs, studying sensitivity to training set size, and testing across multiple LLM backends."

### P1-7｜Conclusion 未提及 limitations 或 future work
- **来源：** L1 (Section Structure)
- **位置：** `sections/conclusion.tex`
- **问题：** 结论段未包含任何关于未来工作或局限性的提及。虽然有独立的 Limitations 节，但 Conclusion 中完全不提显得不完整。
- **修复：** 加 1–2 句，如 "Future work could extend the framework to cyclic dependencies, anonymized schemas, and local open-source LLMs."

### P1-8｜Privacy Preservation 段落过长且混杂多个论点
- **来源：** L2 (Paragraph Coherence)
- **位置：** `sections/experiments.tex` L90 附近
- **问题：** 该段落同时讨论了：(a) fidelity-privacy 张力、(b) StructSynth 隐私优势、(c) Bayesian Sampler 反例论证、(d) DAG 作为正则化器的理论解释。至少 4 个论点挤在一段中。
- **修复：** 拆分为两段：(1) fidelity-privacy 张力 + StructSynth 定位；(2) "高保真不等于高效用" 论证 + DAG 正则化解释。

### P1-9｜Bayesian Sampler 前向引用（在定义前被使用）
- **来源：** L2 (Paragraph Coherence)
- **位置：** `sections/experiments.tex` L90（Privacy 段落）引用了 Section 4.3 才定义的 ablation variant
- **问题：** 读者在 Privacy Preservation 段落中看到 "the Bayesian Sampler ablation achieves the best raw fidelity (48.86) yet the lowest AUC (81.17)"，但此时 Bayesian Sampler 尚未被介绍。
- **修复：** 加括号说明 "the Bayesian Sampler ablation (defined in Sec 4.3; it replaces the LLM generator with a fitted Bayesian network)"，或将该论证移至 ablation 节。

### P1-10｜两个表格使用 `\hline` 而非 booktabs
- **来源：** L7 (Tables & Figures)
- **位置：** `sections/experiments.tex:115`（tab:ablation_study）、`sections/appendix.tex:360`（tab:downstream_sensitivity）
- **问题：** 这两个表格使用 `\hline` 和竖线 `|`，而其他 5 个表格均使用 `\toprule`/`\midrule`/`\bottomrule`。风格不统一，且竖线不符合 EMNLP 排版惯例。
- **修复：** 替换 `\hline` 为 booktabs 命令，移除列规格中的 `|`。
