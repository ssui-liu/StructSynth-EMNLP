# 生成模块的论文对齐与工程决策

核对依据：工作区内 `Latex-EMNLP/sections/method.tex` 的 Graph-Planned
Conditional Synthesis，以及 `Latex-EMNLP/sections/appendix.tex` 的完整算法和
两个生成提示词。本文记录实现时需要作者确认的解释；不声称新实现重现了论文报告的数值。
具体定位：正文 82–104 行、完整算法 139–160 行、提示词 721–839 行。

## 论文定义的执行顺序

- DAG 的同一拓扑层共同生成。父节点必须在更早层，层级由 DAG 计算，不能采用最短路径距离。
- 当前层提示词包含**所有已经生成的列值**。局部诱导子图仍限定为当前层及其直接父节点，
  并显式携带父子关系。正文公式和完整算法的 `x_{<i}` 优先于附录提示词仅称“parent values”的简写。
- 图内的无入边节点属于根层，即使它没有任何边，也不会自动归到图外列。
- 图外列指数据列集合减去图节点集合，在所有图内列之后一次补全，并条件化于全部图内值。
- 当前层的 few-shot 只保留当前层与直接父节点列。图外补全的 few-shot 使用整个训练示例，
  让模型能观察图内值与待补全列的联合关系；这是对附录 `related_few_shot_data` 未明确定义列范围的解释。

## 输出一致性

旧实现按位置和重置后的 DataFrame 索引拼接响应，并在多次失败后允许跳过一致性检查。
新实现使用独立的稳定 `row_id` 对齐请求、响应、局部重试和检查点，响应顺序不参与数据关联。
缺失值只在列模式明确允许空值时接受；缺列不能补 NaN；类型、类别或标识错误不能通过增加重试次数绕过。
响应形状为 `{"rows": [{"row_id": 0, "values": {"feature": 1}}]}`。数据本身的 `row_id`
列可以放在 `values` 内，不与内部标识冲突。未知/重复标识或非法包裹结构使整次响应无效；
合法标识下的缺列、错误类型或非法类别仅使对应行无效，下一次请求只重试未完成行。
完整有效行按原始标识重排输出，不根据响应顺序拼接，也不通过裁掉多余响应恢复“成功”。

一致性检查能够保证行身份、列集合、已有条件值不变、数值类型和类别约束。
它不能证明 LLM 输出满足真实的统计依赖或因果关系；这些性质仍需后续实证评估。

## 有界重试与恢复

独立批次可以并发，单条记录的层依赖必须保持顺序。每个层/批次有明确尝试上限，
失败时返回可定位的错误，不通过无限外循环重新生成，也不交付样本数不足的“成功”数据。
已经验证的局部行必须保存，后续请求只重试缺失或无效的行。

检查点需要绑定图、列模式、few-shot 输入、生成参数和请求样本数。恢复时必须拒绝不兼容的输入，
并继续已有尝试计数。请求发出前记录已消耗的尝试，以避免进程反复退出成为绕开预算的途径。
这意味着请求发出后、响应落盘前退出可能消耗一次尝试而没有可恢复响应；明确报错优于重复无界付费。
每个层/批次独立保存 JSON，使用原子替换和操作系统文件锁。恢复时重新验证每条保存的值、
父值上下文哈希及完成状态；锁会随进程退出释放。并发仅发生在同一层的独立批次，
下一层等待当前层所有批次成功。失败后不继续提交尚未开始的批次；已经运行的独立批次可以完成并落盘。

`batch_size`、`max_attempts`、`seed`、训练数据、few-shot、完整模型配置和样本数均参与指纹。
改变并发数可以继续恢复。达到尝试上限后重启不会增加预算；如需更改参数，应使用新运行目录。
`client.identity` 缺失时仅记录其 Python 类名供简单 mock 使用，不能据此可靠区分两个真实模型配置；
正式客户端必须提供完整身份，API key 的值不写入身份。

所有真实请求的用量和传输重试归共享 LLM 客户端记账，生成器不再次累计，以免重复计费。
失败响应消耗用量也由同一账本保留。生成器事件关联 `request_id`，记录请求行、已接受行、
失败原因、尝试数和恢复记录，便于与请求账本联合检查。

## 方法变化的边界

批量、并发、结构化 JSON、标识校验和原子检查点属于执行可靠性改进。
它们没有引入论文之外的采样分布修正、规则推理器、自动删列或统计拒绝采样。
分类目标的类别域来自训练数据或显式模式，不使用测试集。非目标类别列只在元信息明确提供
`spec.categories` 时强制枚举域；否则校验 JSON 类型，已见训练类别以 `observed_values` 提示，
允许模型生成训练小样本中未出现的合法类型值。论文没有将 few-shot 已见类别作为完整支持集，
因此不能将偶然未见类别自动判为无效。显式域仍是用户给定的硬约束。
连续列同样不默认限制到 few-shot 的最小/最大值，避免把小样本范围误当作真实支持集。
整数须能由最终表格的有符号 64 位整数表示，数值须可转为有限 64 位浮点数。
这是输出存储限制，不是统计范围筛选。布尔值不能冒充整数标签；数值类别采用 JSON number 语义，
因此声明为 `1.0` 的数值类别可接受 JSON 数字 `1`。显式声明类别域时，全部为空的训练类别列也可生成。

`seed` 进入请求及检查点身份，用于追踪实验；它并不保证远程 LLM 的确定性。
并行生成需要线程安全的共享客户端。未调用真实模型，也未声称批量/并发对样本质量没有影响；
质量和性能收益应通过后续相同评估协议的实测判断。

## 已验证的行为

`tests/test_generation.py` 使用模拟响应和本地 transport，覆盖拓扑层条件、图外补全、乱序与部分响应、
类别/类型/空值边界、ID 冲突、有限重试、断点恢复、故障后预算不重置、输入或模型变化拒绝恢复、
检查点损坏、同层并发/跨层等待及统一 Token 用量。不访问模型 API。
