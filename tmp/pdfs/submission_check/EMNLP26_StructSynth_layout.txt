002       Tabular data derives its value from inter-feature
003       dependencies, yet preserving them during
004       synthesis is fragile when samples are scarce.
005       Existing approaches either learn dependencies
006       implicitly through distribution fitting, rely on
007       statistical graph learning that becomes unstable
008       with few samples, or encode structure through
009       flat text serialization. Recent graph-aware
010       methods use dependency graphs as attention

012       but they do not use the graph as a prompt-
013       level plan for organizing the LLM’s own
014       generation process. We introduce StructSynth,
015       a framework that treats a dependency graph as
016       a generation plan—determining the generation
017       order, conditioning context, and scope of

All Feature Descriptions:
{all_features}

Example Data:
{few_shot_data}

Prompt for Link Generation in Dependency Discovery (πgenerate )

You are an expert data analyst building a dependency graph. Based on the following information:
Task Description:
For the given {current_feature}, your task is to propose its direct successors (dependents) from the list of available
features. For each proposed dependency, you must provide a brief, evidence-based rationale.
Current Graph State:
{structure_graph}

All Candidate Features:
{all_features}

Statistical Evidence (Association Scores):
{association_scores}

Example Data:
{few_shot_data}

Your Task is to Propose and Justify New Links:

• Your focus is on the feature: {current_feature}.
• Review the Statistical Evidence, which shows the strength of association between {current_feature} and other
  candidate features {all_features}.
• Based on the statistical scores, the example data, and the existing graph, identify which other features are most likely
  to be direct dependents of {current_feature}.
• For each dependency you propose, you must provide a concise rationale. This rationale should explain why the
  dependency makes sense (e.g., "Higher Education is strongly correlated with and typically precedes higher Income").
• Do not propose links that would create an obvious logical contradiction with the existing graph structure.
• Format your final output as a list of dependency edges and their corresponding rationales.




Prompt for Cycle Resolution in Dependency Discovery (πresolve )
You are a logical reasoning expert tasked with resolving a contradiction in a dependency graph. Based on the following
information:
Task Description:
Analyze the provided dependencies and their rationales within the cycle. Identify the single dependency with the weakest
or least plausible rationale and recommend it for removal to break the cycle.
Conflicting Cycle with Rationales:
{cycle_with_rationales}

Your Task is to Identify the Weakest Link:

• A logical contradiction (a cycle) has been detected in the graph, detailed in Conflicting Cycle with Rationales.
• Your task is to carefully evaluate the rationale provided for each edge in this cycle.
• Based on your analysis of the rationales and any relevant context from the column descriptions or data, identify the
  single weakest link.
• The weakest link is the dependency whose rationale is the least plausible, least supported, or most likely to be spurious.
• Provide your final answer as the single dependency edge that should be removed to resolve the contradiction.

Prompt for Graph-Planned Conditional Synthesis (πdata_gen )

You are a helpful AI assistant that generates realistic tabular data based on structural dependencies.
Task Description:
Generate a realistic synthetic table containing exactly the columns listed in {features_to_generate}. This generation
must be conditioned on the provided values of their parent features.
Conditioning Data (Current Results):
{current_result}

Relevant Dependency Structure:
{related_structure_graph}

Example Data:
{related_few_shot_data}

Your Task is to Generate the Synthetic Data:

• Your primary task is to generate realistic data for the features listed in {features_to_generate}.
• This generation must be conditioned on the data provided in Conditioning Data (Current Results). These are the
  values of the parent nodes that influence the features you are generating.
• The Relevant Dependency Structure shows you exactly how the conditioning features relate to the features you
  need to generate.
• Use the Example Data to understand the format, range, and statistical properties of the real data.
• The generated table should contain columns for exactly the features listed in {features_to_generate}.
• Ensure the generated values are plausible and respect the learned dependencies.




Prompt for Independent Feature Synthesis (πiso )
You are a helpful AI assistant that completes tabular data records by generating values for remaining features.
Task Description:
The core, structurally-dependent features of a dataset have already been generated. Your task is to generate plausible
values for the remaining isolated features, ensuring they are statistically consistent with the core features.
Conditioning Data (Generated Graph-Based Features):
{graph_based_values}

Features to Generate (Isolated Features):
{isolated_features_to_generate}

Example Data:
{related_few_shot_data}

Your Task is to Generate the Independent Values:

• Your primary task is to generate realistic data for the features listed in {isolated_features_to_generate}.
• This generation must be conditioned on the complete set of core features provided in Conditioning Data.
• The features you are generating do not have direct parent-child dependencies in the learned graph, but their values
  should still be plausible and consistent in the context of the entire data record.
• Use the Example Data to understand the typical format and statistical properties of these isolated features.
• The generated table should contain columns for exactly the features listed in {isolated_features_to_generate}.
