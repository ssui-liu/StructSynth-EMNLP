Tabular data underpins high-stakes applications in healthcare~\cite{choi2017generating}, finance~\cite{rundo2019machine}, and education~\cite{luan2021review}, valued for the dependency relationships it encodes among features---these inter-feature dependencies are what enable Machine Learning (ML) models to learn meaningful decision boundaries~\cite{fonseca2023tabular}.
In many such domains, data scarcity poses a fundamental challenge, and synthetic data generation has emerged as a primary remedy~\cite{borisov2022deep}.
Yet effective synthesis must go beyond augmenting volume: it must \textbf{preserve the dependency relationships} inherent in the original data, since downstream models rely on these relationships for generalization~\cite{liu2023goggle, zhao2024tabular}.
When available samples are severely limited, however, the very dependencies that synthesis must preserve become difficult to discover reliably.

As illustrated in Figure~\ref{fig:teaser}, existing generative approaches each sidestep, rather than solve, this dependency discovery challenge.
\textbf{Deep generative models} merge structure discovery and generation into a single end-to-end process, so that both collapse simultaneously when training samples are scarce.
\textbf{Structure-aware methods} isolate graph learning as a prerequisite, yet rely on purely statistical algorithms whose outputs become unreliable under scarcity---errors in the discovered structure propagate directly into generation~\cite{chai2022data}.
\textbf{Large Language Models (LLMs)} bypass explicit structure altogether~\cite{cllm2024}, encoding inter-feature dependencies only implicitly through linearized text rather than exploiting the graphical nature of tabular data~\cite{liu2024rethinking}.
In short, these approaches either \textit{couple} structure discovery with generation---forcing both stages to share the same scarce-sample bottleneck---or \textit{bypass} structure discovery entirely.
This shared failure mode motivates a \textbf{discover-then-synthesize} paradigm that explicitly \textit{decouples} the two stages, reducing per-stage sample complexity so that each can be addressed with complementary signals.

Decoupling yields two key advantages: the structure discovery stage can combine \textit{complementary} signals---LLM semantic priors and statistical association cues---to overcome small-sample instability in either signal alone; the generation stage can treat the discovered structure as a hard generative constraint rather than a soft attention bias, ensuring dependency-faithful synthesis by construction.
These requirements lead directly to \textsf{StructSynth}, a two-stage framework for \underline{Struct}ure-aware tabular data \underline{Synth}esis whose stages mirror the two sub-problems created by decoupling.
In the \textbf{Dependency Structure Discovery} stage, LLM-based reasoning is integrated with statistical evidence to construct a Directed Acyclic Graph (DAG)\footnote{We use ``DAG'' to denote a directed dependency graph used as a generative blueprint, not a ground-truth causal claim.} from limited samples, with a cycle resolution mechanism ensuring acyclicity.
In the \textbf{Structure-Guided Synthesis} stage, this DAG serves as an executable blueprint: synthesis proceeds autoregressively in topological order, with each feature conditioned on its parents, guaranteeing adherence to the discovered dependency graph.
Our contributions are:
\begin{itemize}[leftmargin=*]
    \item We identify \textbf{dependency structure discovery}---not generation model capacity---as the primary bottleneck for tabular synthesis in low-data regimes, and show that existing methods fail because they either couple discovery with generation or bypass it entirely.
    \item Based on this diagnosis, we propose \textsf{StructSynth}, a \textbf{discover-then-synthesize} framework that decouples the two stages: the discovery stage fuses LLM semantic priors with statistical association cues to obtain reliable structures from limited samples, while the generation stage enforces the discovered topology as an executable blueprint for layer-wise synthesis.
    \item Extensive experiments across six datasets demonstrate that \textsf{StructSynth} achieves state-of-the-art \textbf{downstream utility and privacy preservation} while maintaining competitive structural fidelity. Ablations confirm that each stage contributes independently, validating the decoupled design.
\end{itemize}
